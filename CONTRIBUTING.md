# Contributing

Prefer a small correction with a derivation or counterexample over an unqualified new claim. Each theorem must identify its assumptions, the output being measured, the error quantity, the probability mode, and the step-size schedule.

Use GitHub Markdown with `$...$` and `$$...$$` math. Link neighboring chapters and the relevant exercise. Keep hints separate from full solutions. Use synthetic data for reproducible examples, fixed seeds for experiments, and label finite simulations honestly.

Run the repository checker and numerical tests listed in the README. If changing a lab, regenerate its plot and report together. Do not add chat exports, credentials, identifying local paths, graded private assignments, or third-party figures without permission. Do not mark a learning skill demonstrated merely because its solution exists in this repository.

AI-assisted drafts are welcome but require mathematical review. This initial companion was written with AI assistance and checked by derivation and executable examples; it has not received independent peer review. Source issues and uncertainty should remain visible in `notes/precision-notes.md`.
